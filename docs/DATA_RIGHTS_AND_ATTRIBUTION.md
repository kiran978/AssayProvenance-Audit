# Source attribution and licensing / redistribution checks

**No blanket license has been granted by adding research tables to GitHub.** The project owner should select a license for *original analysis code* (for example MIT, if all code authors agree), and a separate license or explicit attribution terms for original derived tables after checking database-source conditions. Do not apply a universal CC0 grant to content derived from multiple external providers.

- **ChEMBL 37**: data originally curated by the ChEMBL team at EMBL-EBI, available through [ChEMBL downloads](https://chembl.gitbook.io/chembl-interface-documentation/downloads); source data commonly provided under Creative Commons Attribution-ShareAlike conditions. Confirm release-specific current terms and preserve attribution before a public database-derived export.
- **PubChem BioAssay**: maintained by the US NIH/NLM/NCBI. Original source records may contain third-party depositor annotations; cite [PubChem](https://pubchem.ncbi.nlm.nih.gov/) and the originating BioAssay AIDs, and review provenance/redistribution restrictions before public release.
- **BindingDB**: developed by BindingDB at UCSD and collaborators; no original full BindingDB 202609 release or 46-case ledger is deposited in this repo. Do not claim that materials not deposited here are openly accessible in this repo.
- Underlying articles, patent documents, and original source images are **not automatically licensed** merely because public abstracts or source identifiers are linked.
- Do **not** include personal reviewer declarations, signatures, email messages or hidden review identity/COI details in a public data release.

The GitHub repository currently remains **private**. A private repository link in a manuscript is **not equivalent to public availability**. If journal reviewers require access before publication, an approved public release or journal-accepted review access method must be arranged by the owner.
