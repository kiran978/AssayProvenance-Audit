# Data and code availability — verified repository status (18 October 2026)

## Text suitable for the manuscript while GitHub access remains private

Derived datasets, analytical code, figure-generation resources and provenance documentation supporting this study have been deposited in a version-controlled GitHub repository (https://github.com/kiran978/AssayProvenance-Audit; currently private). The deposited materials include the ChEMBL 37 strict-S0 304-pair overlap atlas and 64-case source-screening queue, the frozen 43-pair PubChem BioAssay registry and 71-AID source manifest, 24 checksum-verified original PubChem result-table exports from six pilot assay pairs, SID-level KCNK9/TASK3 concordance analyses, source-integrity manifests and scripts for reproducing the reported counts. Public access to the repository has not yet been enabled. The primary ChEMBL 37 database and BindingDB 202609 release files are not redistributed; they should be obtained from their respective original providers under applicable terms. The original final ChEMBL manual-adjudication ledger and BindingDB 46-candidate source-family ledger were not available for this study, and results requiring these inputs cannot be independently reconstructed from the repository.
